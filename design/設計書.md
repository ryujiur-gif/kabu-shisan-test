# 株予想 試験運用プログラム 設計書（2026-11-08）

## 1. 目的と背景
- 世界情勢・イベントを毎朝確認し、日本株の「買い時2銘柄」「売り時2銘柄」をスマホに通知する。
- 当面は**試験運用**。仮想の100万円でおすすめ通りに売買していたら収支がどうなるかを記録し、予想が役に立つかを見極める。
- 成功の姿：毎朝スマホで通知を受け取り、いつでも成績（総資産・損益・日経平均との比較）を確認できること。

## 2. やること / やらないこと
- やる：ニュース調査、銘柄選定、メール通知、仮想売買の記録、成績ページ。
- やらない：実際の証券口座での売買。手数料・税金の計算（当面は無視、後で追加可能）。空売り。
- 失敗とみなす状態：通知が届かない日が続く／記録が実際の株価とずれる／日経平均との比較ができず良し悪しが判断できない。

## 4. 仕組み（Claudeの判断で決めた部分は【案】）
### 4.1 全体構成【案】
- **Claudeのクラウド定期実行（ルーティン）**が毎朝7時（日本時間）に起動。PC不要。
- 記録とプログラムは **GitHub の非公開リポジトリ**（名前案：`kabu-shisan-test`）に保存。
- 決まった計算（株価取得・売買の確定・成績集計・成績ページ作成）は Python プログラムで行い、計算ミスが出ないようにする。
- ニュース調査と銘柄選びは Claude が行い、結果を決まった形式（JSON）でリポジトリに書く。
- メール送信は Gmail コネクタを使う。

### 4.2 毎朝の流れ【案】
1. 休場日（土日・祝日・12/31〜1/3）なら何もせず終了。
2. **前営業日の注文を確定**：前日朝に通知した売買を、前営業日の**始値**で成立させる（売りを先、買いは売却代金も使ってよい）。
3. 前営業日の終値で持ち株を評価し、総資産・損益・日経平均比を記録。
4. ニュースを調べる：前夜の米国市場、為替、金利、地政学、主要企業の決算・材料など。
5. **日経225採用銘柄**から買い2銘柄を選ぶ（持ち株と重複可）。各銘柄に理由（根拠のニュース）と期待度（高・中・低）を付ける。
6. 持ち株から売り2銘柄を選ぶ（持ち株が2未満ならその数だけ、0なら無し）。
7. 注文として記録し、メールを送り、成績ページを更新して GitHub に保存。

### 4.3 売買ルール【案】
- 購入金額：期待度 高=20万円、中=10万円、低=5万円。1株単位（単元未満株）で、`株数 = 金額 ÷ 始値（切り捨て）`。現金不足なら買える分だけ。
- 売却：選ばれた銘柄は**全株**売却。
- 約定価格：通知当日の始値。株価は Yahoo Finance（無料）から取得、取れない場合は別の無料データ（stooq）に切り替え。
- 当日の始値が取れない銘柄（売買停止など）は注文取消として記録。

### 4.4 メールの内容【案】
- 件名例：`【株予想】11/9 買い：トヨタ・ソニー／売り：○○・△△`
- 本文：本日の買い・売り銘柄と理由・期待度、昨日の約定結果、総資産と損益（円・％）、日経平均との比較、成績ページへのリンク。
- 最後に「試験運用・投資判断は自己責任」の注記。

### 4.5 成績ページ【案】
- スマホで見やすい1ページ：総資産の推移グラフ（日経平均に同額投資した場合と並べる）、持ち株一覧（取得単価・現在値・損益）、取引履歴、日々の予想の的中状況。

## 5. 制約・注意点
- 予想の的中は保証できない。成績ページは日経平均との比較で冷静に評価できる形にする。
- クラウド実行は Claude の契約の利用枠を使う（毎朝1回程度）。
- 無料の株価データはクラウドから取得を断られる可能性がある → 作成時に実際に試して確認する。
- 日経225の銘柄一覧は定期的な入れ替えがあるため、ファイルで管理し必要時に更新する。
